Flowheely is a driver-assisted stair-climbing platform (for wheelchairs, and potentially other applications) built around a 4WD articulated chassis with a passive yaw joint. The yaw joint allows the chassis to curve around turning stairs while keeping all four soft airless wheels in contact with the steps. On flat ground, the vehicle can drive in a slipless regime within a 1m turning radius. Tighter turns (up to pure rotation) are also possible with a hybrid skid-steer mode. All modes are unified under a single control interface for seamless driving.

I built this entire project from scratch. This includes mechanical design, fabrication, ROS 2 software architecture, control systems, and computer vision.

Off-the-shelf components include: onboard computer, motors and motor controllers, camera, IMU, encoders, and electrical components.

### Advanced-Driver Assistance System (ADAS)
- classical computer vision for stair detection and collision avoidance
- machine learning for general ADAS features and to improve performance of stair navigation. The stack uses YOLO26 trained on the ADE20K dataset for semantic segmentation.

The platform can detect stairs, and assist with stair climbing and descending (seat leveling auto-engages and vehicle remains square with the leading step) and avoid collisions with obstacles. Work in progress.

## Hardware upgrades

A couple of hardware upgrades have been implemented to improve performance. The original wheels had very uneven radial stiffness which made for a bumpy ride and poor handling, this has proven to be a significant upgrade. The original seat was a quick proof of concept but meant to be replaced, which finally happened! Side rails are being designed as well (not yet implemented). I am also evaluating upgrading the seat actuation for a linear actuator to allow for a self-locking mechanism for safety and power efficiency.
